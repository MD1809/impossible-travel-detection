# Impossible Travel Detection System

## Giới thiệu
Hệ thống phát hiện di chuyển bất khả thi (Impossible Travel Detection) dành cho môn học **Bảo mật ứng dụng và hệ thống**.

### Công nghệ sử dụng:
- **Backend:** Java 17+, Spring Boot 3, Spring Security, MaxMind GeoLite2
- **Frontend:** ReactJS, Vite
- **Database:** MySQL 8.x
- **Testing:** Postman
